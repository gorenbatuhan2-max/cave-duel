# Roadmap

Cave Duel started as a single-file browser prototype. The goal is to grow it
into a real, published mobile application.

## Now — browser prototype
- Single-file HTML5 / Canvas game, playable on desktop and mobile browsers.
- Three UI experiments (`1.html`, `2.html`, `3.html`); `3.html` is the main build.
- Core loop: idle auto-battle, four enemy types, loot, coins, offline rewards.
- All art is CC0 / redistributable (see README credits).

## Next — mechanics polish
- Tune combat balance and pacing based on player feedback.
- Consolidate the three UIs into one main build.
- More enemy types, stages, and equipment.
- Sound effects and music (CC0 sources).

## Later — ships as a real app 📱
Cave Duel is planned to become a downloadable **mobile app**. The intended path
is to wrap the HTML/JS build with [Capacitor](https://capacitorjs.com/) and
publish an **Android APK** (with iOS to follow if it lands well).

> The author is not a professional developer, so the app-packaging steps will be
> documented and done one step at a time.
